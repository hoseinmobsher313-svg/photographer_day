# Happy World Photographer's Day

A standalone HTML/CSS/JS page based on the requested camera + flashlight + watercolor/rain concept.

## Run in VS Code
1. Open this folder in VS Code.
2. Install the **Live Server** extension if needed.
3. Open `index.html`.
4. Click **Go Live** or right-click `index.html` → **Open with Live Server**.

## Controls
- Click the flashlight to switch it on/off.
- Use the brightness slider.
- Click the bell, or drag it downward, to reveal the camera panel; it hides automatically.
- Choose 1080p / 4K / 8K and use **Download WebM** to record a short animated version.
- **Share / Copy link** uses your browser's sharing feature when available.

## Important
The supplied camera image is 1536×1536. The 4K/8K export options can upscale it, but they cannot create true extra camera detail that is not present in the source image.

For a public Google-accessible download page, upload this folder to a hosting service (for example GitHub Pages, Netlify, or another static host). A `127.0.0.1:5500` address only works on the computer running VS Code.
